# SolidityChain

Transfers data between Solidity smart contracts on Ethereum and other blockchain networks in a secure and reliable manner.

The key benefits of using SolidityChain include:

- Transfers data between Solidity smart
- contracts on Ethereum and other
- blockchain networks in a secure

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityChain.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SolidityChain is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
